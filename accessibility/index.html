株式会社 KANOPY は、ROUNDIE のウェブサイトおよびアプリケーションが、できる限り多くの方にとって利用しやすいものであることを目指しています。視覚・聴覚・運動機能・認知に何らかの制約をお持ちの方を含め、すべてのユーザーに同等の体験をご提供することは、私たちの基本姿勢です。

1. 準拠する基準

ROUNDIE は以下の基準への準拠を目標としています。

  • WCAG 2.2 AA（Web Content Accessibility Guidelines、World Wide Web Consortium）
  • 障害者差別解消法（日本・2024 年 4 月より民間事業者の合理的配慮も義務化）
  • 欧州アクセシビリティ法（EAA）（2025 年 6 月施行予定）

2. 当サイトで実装しているアクセシビリティ機能

知覚可能（Perceivable）

  • テキストと背景のコントラスト比は WCAG AA（4.5:1 以上）を満たします
  • すべての画像に代替テキスト（alt 属性）を提供しています
  • 装飾的な画像には alt="" と role="presentation" を使用し、スクリーンリーダーに読み上げさせません
  • テキストサイズは 200% まで拡大しても破綻しません（clamp() ベースのレスポンシブタイポグラフィ）

操作可能（Operable）

  • すべての機能はキーボードのみで操作できます（Tab / Shift+Tab / Enter / Esc）
  • フォーカス位置は常に可視（:focus-visible リング、緑 2px・オフセット 3px）
  • タッチターゲットは最小 44×44 px（WCAG 2.2 新基準 24×24 px を上回る）
  • 「Skip to content」リンクをページ最上部に配置（Tab キー 1 回で到達）
  • マーキー・自動再生動画は使用していません
  • セッションタイムアウトはありません

理解可能（Understandable）

  • <html lang> 属性で言語を明示。多言語 span には lang 属性を個別付与
  • フォームエラーは原因と修正方法を明示
  • ナビゲーションはサイト全体で一貫

堅牢（Robust）

  • セマンティック HTML を優先（<header> / <nav> / <main> / <section> / <article> / <footer>）
  • ARIA は必要最小限。ネイティブ要素を優先
  • VoiceOver / NVDA / TalkBack での読み上げを検証

動きへの配慮

  • prefers-reduced-motion: reduce の設定を尊重し、アニメーションを停止します
  • カスタムカーソル（PC のみ）は prefers-reduced-motion 時に非表示
既知の制約: ROUNDIE LP は GitHub Pages 上でホストされているため、サーバーレベルでのセキュリティヘッダ（HSTS / COOP / 厳密な CSP）の設定に一部制約があります。今後 Cloudflare Pages への移行を検討しています。
