# 01. Target Persona

## Persona A — 「映えたい新規ゴルファー」（推定 60% / Primary）

| 軸 | 内容 |
|---|---|
| 名前(仮) | Yuki, 28歳 |
| 性別 / 年齢 | 女性 25-32 歳 |
| 居住地 | 東京・大阪・名古屋の都市部 |
| 職業 / 年収 | 広告/PR/コンサル/IT — 400-650 万 |
| ライフスタイル | 独身 or DINKs、Instagram 1日 30分、TikTok 1日 15分 |
| ゴルフ歴 | ラウンド開始 1-3 年、年 5-15 ラウンド |
| 普段のスコア | 100-130 |
| デバイス | iPhone 15/16、Mac は持ってない |

### JTBD (Jobs To Be Done)
- **機能的ジョブ**: ラウンドの楽しい時間を SNS で見栄え良くシェアしたい
- **情緒的ジョブ**: ゴルフをやっている自分を見せたい。でもスコアは恥ずかしい
- **社会的ジョブ**: 同世代の女子ゴルファー仲間とつながりたい

### 来訪チャネルと温度感
| チャネル | 温度 | LP に求めること |
|---|---|---|
| Instagram 広告 | 冷 | **5秒で「自分に関係ある」と分かる** + 続きを読ませる |
| TikTok 広告 | 冷 | **動画と矛盾しないヒーロー** |
| 友人紹介 LINE | 温 | 友達が言ってたあれ、を確認 |
| 検索「ゴルフ アプリ おしゃれ」 | 温 | 既に関心あり、機能比較したい |

### 競合代替（Persona A が今やっていること）
- Instagram で手撮り写真をストーリーズ投稿（恥ずかしいので顔は出さない、ゴルフ場の景色だけ）
- LINE で友人にスコアを写真で送信
- 何も残さない（一番多い）

### 設計示唆
- ヒーローは **情緒・映え・記憶** を訴求
- スコア値は出さず、**カラーグリッドだけ** を主役にする
- 「インスタっぽい配色・余白」より「**Brutalist + 緑差し色**」で**他のゴルフアプリと違う**感を演出
- 「あなただけの色」「世界に一つだけ」コピーが効く

## Persona B — 「数字以外で成長を測りたい男性ライト層」（推定 30% / Secondary）

| 軸 | 内容 |
|---|---|
| 名前(仮) | Kenji, 32歳 |
| 性別 / 年齢 | 男性 28-36 歳 |
| 居住地 | 関東圏（埼玉・千葉含む） |
| 職業 / 年収 | 営業/IT/メーカー — 500-800 万 |
| ライフスタイル | 既婚、Strava で週末ランニング、ジムも通う |
| ゴルフ歴 | 開始 2-5 年、年 8-20 ラウンド |
| 普段のスコア | 95-115 |
| デバイス | iPhone + Apple Watch |

### JTBD
- **機能的ジョブ**: 自分の成長を数字以外で実感したい（スコアは横ばい）
- **情緒的ジョブ**: 上手な先輩に勝てる軸が欲しい（VIBE / STYLE で勝つ）
- **社会的ジョブ**: 同じレベルの仲間と繋がりたい、Strava のような Kudos 文化が欲しい

### 来訪チャネルと温度感
| チャネル | 温度 | LP に求めること |
|---|---|---|
| 検索「ゴルフ アプリ 楽しい」 | 中 | 機能を見せて欲しい |
| 検索「ゴルフ Strava」 | 温 | まさに探していたもの感 |
| Reddit / X | 温 | 他のレビューも気になる |

### 競合代替
- 18Birdies で GPS だけ使用
- Excel でスコア管理
- 何も使わず Apple ノートにスコアだけメモ

### 設計示唆
- ROUNDIE Score の **3 軸（SKILL/VIBE/STYLE）** がメインピッチ
- 「**スコアが伸びなくても成長できる**」が刺さる
- Strava 風の **Kudos / フィード / ランキング** をしっかり見せる

## Persona C — 「コンペ幹事ストレスを減らしたい中堅」（推定 10% / Tail）

| 軸 | 内容 |
|---|---|
| 名前(仮) | Hiroshi, 38歳 |
| 性別 / 年齢 | 男性 30-45 歳 |
| 居住地 | 全国 |
| 職業 / 年収 | 中間管理職/中小企業オーナー — 700-1200 万 |
| ライフスタイル | 会社の付き合いコンペ・接待コンペの幹事を年 4-8 回 |
| ゴルフ歴 | 10年以上 |
| 普段のスコア | 85-100 |
| デバイス | iPhone + iPad（接待で iPad 持参） |

### JTBD
- **機能的ジョブ**: 集計を自動化したい。手集計の地獄から逃れたい
- **情緒的ジョブ**: 幹事の自分が「できる男」に見えたい
- **社会的ジョブ**: 接待相手の役員・取引先に印象付けたい

### 来訪チャネルと温度感
| チャネル | 温度 | LP に求めること |
|---|---|---|
| 検索「ゴルフ コンペ アプリ 自動集計」 | 熱 | 機能と価格を即見たい |
| 検索「ゴルフ コンペ 集計 アプリ 無料」 | 熱 | 無料で使えるかを最初に知りたい |

### 競合代替
- Excel テンプレ
- Golf Network Plus（中小企業向け）
- 楽天 GORA（予約と集計両方）

### 設計示唆
- **Comp Pack $9.99 単発** を強調（サブスク強制しない安心感）
- Free プラン「**月1コンペ・8名まで**」も明示
- **3 タップで開催** ＝幹事ストレスゼロ訴求
- Pricing セクションの直前に「コンペ幹事のあなたへ」を配置

## ペルソナ別の LP 接触順（スクロール）

| スクロール位置 | プライマリ視線 | 設計意図 |
|---|---|---|
| ヒーロー | Persona A | 情緒・映え。**3秒で「映える」と分かる** |
| Vision | A + B | 「数字じゃない価値」を共通の入り口に |
| HowItWorks | A + B + C | 全員に基本を理解させる |
| Features (前半) | A | Round Card・Feed・Kudos |
| Features (後半) | B + C | ROUNDIE Score・Ranking・Competitions |
| Pricing | C → B → A | **Comp Pack** を最初に見せて C を捕まえる |
| Final CTA | 全員 | TestFlight + Email の二択 |

3 人の視線が **意図的に切り替わる** よう設計する。
