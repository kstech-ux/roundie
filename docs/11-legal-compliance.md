## 同意管理（CMP）

### 対応すべき法規
| 地域 / 法規 | 概要 |
|---|---|
| **GDPR (EU)** | EU 訪問者には事前同意必須。デフォルト「拒否」 |
| **ePrivacy Directive** | Cookie 利用前の同意必須 |
| **CCPA / CPRA (米加州)** | "Do Not Sell My Personal Information" リンク |
| **APPI (日本・2024 改正)** | 個人関連情報の第三者提供は同意必要、開示請求窓口 |
| **LGPD (ブラジル)** | GDPR と同等の同意取得 |
| **PIPEDA (カナダ)** | 同意とアクセス権 |

### 実装方針
- 訪問者の地理判定なしで **全員にバナー表示**（最も厳しい GDPR に揃える）
- 同意状態は localStorage に保存（90 日有効）+ サーバー側 Edge Function でも保管（証跡）
- 同意前: GA4 / Clarity / Pixel **すべて発火停止**（Consent Mode v2 で制御）
- 「Customize」で個別カテゴリ選択可能

## 個人情報保護法（APPI）対応

### プライバシーポリシーに含むべき項目
1. **取得する個人情報の種類**
   - メールアドレス（Email 登録時）
   - Cookie / IP アドレス（計測時、同意後のみ）
   - 名前（任意）
2. **利用目的**
   - サービス提供
   - ローンチ告知メール送信
   - サービス改善のための統計分析
3. **第三者提供**
   - 計測パートナー: Google (GA4), Microsoft (Clarity)
   - Apple (TestFlight 経由のアプリ提供)
   - **広告パートナー**（同意した場合のみ）: Google, Meta
4. **保管期間**
   - メアド: 登録解除まで（解除後 30 日で完全削除）
   - 同意ログ: 5 年
5. **開示・訂正・削除請求窓口**
   - メール: `privacy@kanopy-inc.com`
   - 対応期限: 受領後 30 日以内

### 個人関連情報（Cookie）の扱い
- Cookie ID 単体では個人情報ではないが、**他情報と紐付ける場合は同意必要**
- Consent Mode v2 で適切に制御

## 景品表示法（日本）

### 禁止表現チェック
| NG | 理由 |
|---|---|
| 「No.1 ゴルフアプリ」 | 根拠提示なし → 優良誤認 |
| 「業界初」 | 「同等機能の競合が無いこと」の証明必要 |
| 「最高の体験」 | 主観表現は注意 |
| 「最安」 | 根拠と打消し表示必要 |

### 使える表現
- 「他のゴルフアプリにはない、カラーグリッド表示」（**事実を具体的に**）
- 「ROUNDIE 独自の 3 軸スコア」（**「独自」は事実）|

### 価格表記
- 「Pro $4.99/月」が **税込・税抜どちらか明示**（Apple ID 経由のため税は地域による → 「税抜・地域により変動」と注釈）
- 割引「2 months free · 17% OFF」は **打消し表示明確に**：「年額プランで月額換算」と注釈

## アクセシビリティ法規

### 障害者差別解消法（2024/4 民間も合理的配慮義務化）
- 視覚障害者・聴覚障害者・運動障害者へのアクセス保障
- 「合理的配慮」: 申出があった場合、過重な負担にならない範囲で対応

### 欧州アクセシビリティ法（EAA, 2025/6 施行）
- EU 域内向けデジタルサービスに **WCAG 2.1 AA 相当の準拠** が義務化

### 対応方針
- **WCAG 2.2 AA を達成**（[02.A](./02-voice-and-tone.md) ではなく実装で）
- アクセシビリティ声明ページを `/accessibility/` に新設
- 連絡先（アクセス困難時の問い合わせ窓口）

`/legal/sct/` ページ新設。記載項目:
- 販売業者: 株式会社KANOPY
- 運営統括責任者: [代表者名]
- 所在地: [本社住所]
- 連絡先: support@kanopy-inc.com
- 商品代金: $0 (Free) / $4.99 (Pro Monthly) / $39.99 (Pro Yearly) / $9.99 (Comp Pack)
- 支払方法: Apple ID 決済
- 支払時期: 購入時即時
- 商品の引渡時期: 購入後即時利用可能
- 返品・キャンセル: Apple のポリシーに準ずる（Pro: 解約後も期間終了まで利用可能 / Comp Pack: consumable のため返金不可）

> Apple ID 決済のため、特商法上の販売者は Apple Inc. であるという解釈もあるが、念のため記載しておく方が安全。
