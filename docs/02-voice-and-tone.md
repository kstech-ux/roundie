# 02. Voice & Tone

## ボイス（恒常的な性格）

ROUNDIE LP のボイスは:
- **静かに自信がある**（Confident, Quiet）
- **詩的だが正直**（Poetic but Honest）
- **媚びない**（Not eager-to-please）
- **派手ではない、しかし退屈でもない**（Subtle, not boring）

例えるなら: **Apple の HIG ドキュメント × Letterboxd のカード文 × ヴィシニェフスキの小説の一節**。

## トーン（場面ごとに変わる）

| 場面 | トーン |
|---|---|
| ヒーロー | **詩的・宣言的**。「記憶を、かたちに。」のような一行で殴る |
| Vision | **会話的・誘い込む**。「ゴルフは、スコアだけじゃない。」と読者の同意を引き出す |
| HowItWorks | **明快・実用的**。「30秒で完成」「3 タップで開催」と数字で具体化 |
| Features | **クールな機能説明**。形容詞を抑え、機能の事実を述べる |
| Score 説明 | **教育的・正直**。「SKILL・VIBE・STYLE の 3 軸。課金で順位は買えない」と仕組みを開示 |
| Pricing | **率直・押し付けない**。「Free で十分」を最初に言える誠実さ |
| Trust & Privacy | **温度を上げる**。「あなたのデータは、あなたのもの」と一人称で語りかける |
| Final CTA | **背中をそっと押す**。「今日のラウンドから始める」 |

## 人称

- **一人称**: ROUNDIE は「私たち」と書かない。**「ROUNDIE は…」「ROUNDIE が…」** と固有名詞で語る
- **二人称**: 「あなた」を中心に。「皆さん」は使わない（距離感が出る）
- **三人称**: 「ユーザー」と書かない。「ゴルファー」「あなた」「仲間」と言い換える

## 敬語レベル

- **JA**: 「です・ます」基本。「お客様」「ご利用」等の過剰敬語は避ける。**くだけ過ぎず、堅すぎず**
- **EN**: Conversational but precise. Avoid "we're thrilled to..." or "supercharge"
- **KO**: 합니다체基本。해요체は避ける（プロダクトとしての毅然さを保つ）

## 使う語 / 使わない語

### ✅ 使う
| カテゴリ | 語 |
|---|---|
| キーワード | 記憶 / かたち / ラウンド / 仲間 / グリッド / 残す / 響く |
| 動詞 | 記録する / かたちにする / シェアする / 残す / 振り返る / つながる / 育てる |
| 形容詞 | 美しい / 静かな / 確かな / 唯一無二の |
| EN | shape / keep / round / memory / craft / lasting |
| KO | 형태로 / 남기다 / 라운드 / 동료 / 추억 |

### ❌ 使わない（**禁止表現**）
| カテゴリ | 語 | 理由 |
|---|---|---|
| AI 臭バズワード | 革命的 / 究極の / 次世代 / 加速 / 進化させる | 内容空虚な煽り表現 |
| EN AI 臭 | Supercharge / Revolutionize / Game-changer / Cutting-edge / Unleash | 同上 |
| 自慢系 | 業界初 / No.1 / 最も / 究極 | 景表法リスク（根拠表示が必要）|
| 媚び系 | 是非 / お気軽に / どうぞ / ぜひぜひ | 距離感が遠い |
| 否定形 | スコアを見せない（主訴求） | [feedback_no_score_hiding_messaging](../../.claude/projects/-Users-kazushigeshiba--secretary/memory/feedback_no_score_hiding_messaging.md) PM 確定 |
| 商標 | Wordle / Strava風 | 商標侵害リスク（Wordle は特に NG）|
| 一般動詞濫用 | する/やる/できる | 動詞は具体的に |

## 例文（5 種類）

### ヒーロー
- ❌ Bad: 「ROUNDIE で、ゴルフを革命せよ！次世代のゴルフ体験。」
- ✅ Good: 「**記憶を、かたちに。** ラウンドが、世界に一つだけのカラーグリッドになる。」

### Vision
- ❌ Bad: 「私たちは、ゴルフをもっと楽しくしたいと考えています！」
- ✅ Good: 「**ゴルフは、スコアだけじゃない。** フェアウェイの 4 時間。会話、笑い、復活のパット。」

### Features 説明
- ❌ Bad: 「最先端の AI を活用したスコアリングシステム！」
- ✅ Good: 「SKILL・VIBE・STYLE の 3 軸。**課金で順位は買えません。**」

### Pricing
- ❌ Bad: 「まずは無料でお試しください！」
- ✅ Good: 「**Free で、ほぼ全部できる。** Pro は本気になったら。」

### Final CTA
- ❌ Bad: 「今すぐ無料でダウンロードしよう！！」
- ✅ Good: 「**今日のラウンドから、残していく。** TestFlight で体験。」

## トーンチェックリスト（コピーを書いた後に必ず通す）

- [ ] 「私たち」を使っていない
- [ ] 形容詞が3 つ以上連続していない
- [ ] バズワードが入っていない
- [ ] 一文 40 字（JA）/ 80 字（EN）以下
- [ ] 助動詞「思います・考えます」が無い
- [ ] AI に書かせたら出てきそうな文型になっていない
