技術メモ

全 9 案: 独立 HTML 1 枚、外部依存最小。アプリのブランドトークン（Arial Black 900 ／ #2D5A27 ／ #0A0A0A ／ scoreEagle #F5C400 etc.）を共通使用。動きの実装方針:

  • CSS-only: A · B · C · D · G · H · I（animation-timeline: view() + IntersectionObserver fallback）
  • JS あり: E（カスタムカーソル）・F（インタラクティブ Round Card）・H（章 progress rail）
  • 全案 prefers-reduced-motion:reduce 完全対応・noindex,nofollow

選定後の進め方

  • 1 案選択 → その方向性で roundie.app/ 本番ページに正式実装
  • 続いて kanopy-inc.com/、talent / faq / notice / privacy / terms と順次同じ言語で展開
  • 並行して React Native Simulator で実機 SS を生成し、Hero / Features に配置
  • ハイブリッド（"G の構成 + I の背景 + C のロゴ" 等）も可能
