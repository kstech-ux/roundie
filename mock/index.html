選んでください。

PM のフィードバックを受けて、現状の HP リデザインの方向性を 3 つの異なるコンセプトで作成しました。各モックは実際にブラウザで開いて、スマホ / iPad / PC で挙動・字体・密度を比較できます。1 つを選んでいただければ、その方向性で全 7 ページを本実装します。

Option A

Minimal Editorial

Apple / Linear / Notion 寄り。余白を多めに取り、細い線と細めのタイポでクラスを表現。Wordmark は Arial Black、本文は light weight でコントラスト。装飾より情報構造で語る。

比較ポイント

スマホ / iPad / PC それぞれで開いて、特に下記を意識してください:

  • 第一印象 — Hero を見た瞬間「これ良い」「これダサい」の体感
  • アプリとの統一感 — ROUNDIE という字体や緑の色味がアプリと連続しているか
  • メリハリ — Round Card や ROUNDIE Score の独自性が伝わるか
  • 触感 — ボタン、カードへの hover/tap の反応が気持ち良いか
  • Pricing UI — 価格テーブルがどれが一番読みやすいか
  • Footer の納まり — ページ最下部が締まって見えるか

技術メモ

各モックは独立した HTML 1 枚で実装されており、外部依存なし（fonts は system / Arial Black 系のみ）。ブランドトークンはアプリの constants/brand-tokens.ts を参照しました（緑 #2D5A27、Arial Black 900、letter-spacing 6-8px、背景 #0A0A0A、scoreEagle #F5C400、scoreBogey #60A5FA など）。

3 案ともコピーは現状の本番 HP と同等のものに揃えてあります（実際の Features / Pricing 文言 と矛盾しないように）。
